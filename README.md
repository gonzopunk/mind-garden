# Mind Garden

A contemplative plant-growing game for the browser. Tend one plant at a time through daily breathing exercises and mindful actions. Watch it grow slowly. Place it on the windowsill. Return tomorrow.

Mind Garden is a personal experiment in dopamine resilience — a game designed to be the structural opposite of compulsive reward loops. Progress is slow, irreversible, and calm. There are no leaderboards, no streaks with punishments, no sudden reversals.

The game runs entirely in the browser with no backend, no accounts, and no data collection. Your garden is saved locally.

**[Play it here](https://gonzopunk.github.io/mind-garden/)** *(if GitHub Pages is enabled)*
